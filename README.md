# Lista de Tareas - Cipher 📝

Una aplicación ligera, intuitiva y enfocada en la productividad para organizar tus tareas pendientes con prioridades, fechas de vencimiento y categorías.

Desarrollada en **Python** utilizando el framework **Kivy**.

---

## 🚀 Características Principales

* 🎯 **Gestión de Tareas:** Organiza tus pendientes con un sistema intuitivo de categorías (Trabajo, Hogar, Personal, Proyectos).
* 🚦 **Priorización basada en Matriz de Eisenhower:** Clasificación por urgencia e importancia (Hacer hoy, Programar, Delegar/Rápida).
* 📅 **Fechas y Horas de Vencimiento:** Recordatorios dinámicos y tareas recurrentes (Diaria, Semanal, Mensual).
* 🤖 **Importación por Texto Libre:** Escribe varios pendientes en lenguaje natural y la app los procesará automáticamente.
* 🔒 **100% Privada y Sin Anuncios:** Tus tareas se guardan de forma local en tu dispositivo. Sin registro ni rastreo de datos.

---

## 📲 Descarga e Instalación

Puedes descargar el archivo `.apk` directamente desde la sección de **Releases** en GitHub o compilar la aplicación utilizando `buildozer`.
